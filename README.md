# 職場英文 30 天

> 30 天的職場英文計劃：每天練習一段情境對話，學完馬上應用在工作上！

給上班族的職場英文自學網站。每一課有一段職場情境對話、單字、片語、文法、造句句型和延伸小練習，角色對話都有真人感的預錄語音。不需要安裝、不需要帳號，打開網頁就能用。

---

## 怎麼打開

- **直接開啟**：雙擊 `index.html`，用瀏覽器開啟即可。
- **本機伺服器（選用）**：在專案資料夾執行 `python -m http.server 8765`，再打開 <http://localhost:8765>。

`index.html` 和 `audio/` 資料夾要放在一起，對話才會有預錄語音；少了 `audio/` 一樣能用，只是會改用瀏覽器內建的聲音朗讀。


## 課程架構

6 個單元 × 每單元 5 課 = 30 課。

| 單元 | 主題 | 課程 |
| --- | --- | --- |
| 01 | 自我介紹與認識團隊 | 自我介紹、認識團隊與角色、第一次開會、回應日常寒暄、茶水間閒聊 |
| 02 | 與主管 1on1 溝通 | 更新工作進度、請求協助、討論目標、接受回饋、提出想法與職涯規劃 |
| 03 | 會議中的表達與確認 | 會議中插話與發言、報告進度、被問倒時怎麼回、表達同意與補充、委婉表達不同意 |
| 04 | 回報問題與提出對策 | 回報延誤、解釋原因、提出解決方案、評估風險、協商期限 |
| 05 | 跨部門協調與跟進 | 請求資源支援、跟進進度、對齊期望、處理意見衝突、分派任務 |
| 06 | 數據報告與會議總結 | 用數據說話、會議總結與待辦事項、會後 email 跟進、視訊會議狀況處理、30 天綜合模擬 |

### 每一課的內容

1. **情境對話**：6～8 句，可以單句播放或「播放整段」。
2. **單字**：5 個，附例句。
3. **片語**：3 個，附例句，以及「也可以說」的替代說法（點一下就能聽）。
4. **文法重點**：1 個，附 2 個例句。
5. **造句句型**：3 個，空格處換成自己的內容練習。
6. **延伸小練習**：25 課有。Alex（你）的台詞先蓋住，顯示「你會怎麼回？」，點一下才看到答案。
7. **補充：說故事技巧**：8 課有（第 1、3、6、8、16、18、26、27 課）。

### 角色

| 角色 | 身分 | 預錄聲音 |
| --- | --- | --- |
| Emma | 主管（女） | en-US-AriaNeural，自信 |
| Ryan | 工程師（男） | en-US-ChristopherNeural，低沉穩重 |
| Emily | 規劃團隊（女） | en-US-AvaNeural，親切 |
| Alex | 你（男） | en-US-BrianNeural，年輕隨和 |

## 功能

- **完成進度**：每一課右上角顯示「已完成 N%」，依照頁面捲動的比例計算，只記錄讀到最遠的位置。讀到 90% 自動標記完成，也可以點標籤手動取消或標記。
- **首頁**：下一課卡片、6 個單元卡片（編號＋單元完成進度條）、30 課的學習進度點點。
- **學習方法頁**：導覽列的「口說學習方法」，教使用者每天 10 分鐘怎麼練，共三步：① 聽懂（約 2 分鐘）② 跟讀 Shadowing（約 5 分鐘）③ 練習產出 Output（約 3 分鐘：造句、延伸小練習、AI 角色扮演、朋友或口說課）。附可以一鍵複製的 AI 角色扮演提示。內容在 `METHOD`、`AI_PROMPT`。
- **收藏**：對話、單字、片語、文法、句型都能點星星收藏，收藏頁可以篩選類型、用翻卡複習（支援鍵盤左右鍵、空白鍵翻面）。
- **語音**：
  - 對話（主對話＋延伸小練習）播放預錄 MP3，每個角色聲音固定，所有裝置聽起來都一樣。
  - 單字、片語、句型使用瀏覽器內建語音朗讀。
  - 換頁或關閉翻卡時，正在播放的語音會自動停止。
  - 預錄音檔載入失敗時，自動改用瀏覽器語音。
- **動畫**：換頁淡入、卡片與按鈕的彈跳回饋、課程頁內容隨捲動出現（Q 彈效果，已出現的不會再消失）、收藏和完成時的糖粒特效。系統開啟「減少動態效果」時會自動關閉。
- **手機版**：導覽列移到底部，首頁文字置中，版面單欄。

### 資料儲存

收藏、完成進度、閱讀百分比、語音設定都存在瀏覽器的 localStorage，**換裝置或清除瀏覽器資料不會保留**。

| 鍵值 | 內容 |
| --- | --- |
| `mt-favs` | 收藏的項目 |
| `mt-done` | 已完成的課程編號 |
| `mt-undone` | 使用者手動取消完成的課程（不會再自動標記） |
| `mt-read` | 每一課讀到的最遠百分比 |

## 怎麼修改內容

所有課程內容都在 `index.html` 的 `<script>` 裡：

| 想改什麼 | 找這個變數 |
| --- | --- |
| 單元名稱、顏色、說明 | `UNITS` |
| 30 課的標題（英文、中文） | `DAYS` |
| 每一課的對話、單字、片語、文法、句型、說故事技巧 | `LESSONS` |
| 延伸小練習 | `MINI` |
| 片語的「也可以說」 | `ALTS`（第 4、11、13 課直接寫在片語的第 5 個欄位） |

對話的格式是 `["角色","英文","中文"]`，角色只能是 `Emma`、`Ryan`、`Emily`、`Alex`。

### 改了對話之後：重新產生音檔

```bash
pip install edge-tts
python tools/make_audio.py
```

- 只會產生新增或修改過的句子，沒改的直接沿用。
- 不再使用的舊音檔會自動刪除，`audio/manifest.js` 會自動更新。
- 沒有重新產生也不會壞，新句子只是會改用瀏覽器語音朗讀。

**關於 edge-tts**：這是開源套件，借用 Microsoft Edge「大聲朗讀」的線上語音，不需要帳號或金鑰。它不是微軟官方開放的 API，適合個人學習用途；如果之後要商業販售，建議改用 Azure 語音服務等官方付費方案（聲音是同一套）。

## 重要決定紀錄

| 決定 | 原因 |
| --- | --- |
| 對話改用預錄 MP3，單字片語維持瀏覽器語音 | 瀏覽器能用的聲音由各裝置決定，手機常常只有一個聲音，音高調整也不是每個瀏覽器都支援，無法保證角色聽起來不同。只有對話需要分辨角色，所以只錄對話。 |
| 不在點擊時即時呼叫線上語音服務 | 需要把金鑰放進網頁（會被盜用）或另外架伺服器；預錄 MP3 對靜態網站最簡單穩定。 |
| 用「第 N 課」取代「Day N」，首頁不列日期範圍 | 使用者不一定會連續 30 天學習，中間可能中斷。網站名稱保留「30 天」。 |
| 完成改成依捲動比例計算 | 比「一打開就算完成」更準確；門檻 90%。 |
| 第 4、11、13 課改寫 | 原本的「詢問工具與流程」「會議開場與議程」「確認理解」改成更常遇到的「回應日常寒暄」「會議中插話與發言」「被問倒時怎麼回」；舊內容濃縮成這三課的延伸小練習。 |
| 延伸小練習只蓋住 Alex 的台詞 | 保留其他人的對話脈絡，學習者先想再看答案。 |
| 規劃團隊的角色從 Mia 改名為 Emily | 名字的考量。 |
| 不提供「收藏整段對話」 | 不實用，改成逐句收藏。 |
| 拿掉「語音設定」視窗和語速切換 | 對話改用預錄語音後，選聲音的功能沒有意義；語速切換也決定不需要，介面保持簡單。 |

## 之後可以考慮

- 收藏和進度跨裝置同步（需要登入或後端）。
- 課程大綱和課程頁的單元圖示，統一換成同一套風格（目前第 1 單元已換成名片圖示）。
- Emma 和 Emily 的頭像都顯示「E」，目前靠顏色區分（粉紅／淡紫）。
- 把 `index.html` 拆成「頁面」「課程資料」「圖片」幾個檔案，方便多人編輯。
